부위 선택 시 해당 운동 목록이 자동으로 표시됨

저장 시 Firebase(Firestore)에 즉시 반영되며 로그인된 다른 기기에도 실시간으로 동기화됨. 오프라인 상태에서 저장하면 온라인 복귀 시 자동으로 반영됨.

머신/케이블 등 스택 무게 기준. 맨몸 운동은 체감 강도(레벨) 값을 입력. 세트마다 중량을 다르게 입력 가능(예: 웜업·드롭세트).

자동 계산 볼륨 (세트별 중량 × 반복의 합) 0 kg

입력 가이드

· 볼륨 = 세트별(중량(kg) × 반복수)의 합
· 세트마다 중량을 따로 입력 가능(웜업·드롭세트 등)
· 세트는 최소 1개, 최대 10개까지 추가 가능
· 부위–운동 매핑은 기존 시트의 드롭다운 목록을 그대로 반영함
